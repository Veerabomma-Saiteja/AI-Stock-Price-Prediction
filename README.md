# 📈 AI Stock Price Prediction using LSTM

This project predicts stock price trends using Deep Learning (LSTM) and technical indicators.

## 🚀 Features
- Historical stock data from Yahoo Finance
- Technical indicators (RSI, MACD, Moving Average)
- LSTM neural network for prediction
- Streamlit dashboard for visualization

## 🛠 Tech Stack
- Python
- TensorFlow / Keras
- Pandas, NumPy
- Streamlit
- yfinance
- ta (technical indicators)

## 📊 How It Works
1. Collect stock data
2. Add technical indicators
3. Preprocess data into sequences
4. Train LSTM model
5. Predict stock prices
6. Visualize results in dashboard

```bash
pip install -r requirements.txt
python -m streamlit run app.py
